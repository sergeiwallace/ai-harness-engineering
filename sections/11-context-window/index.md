# Context window and memory

As of 2026-11-09.

Stop 8 on the talk path, about 2 minutes.

- The risk of mistakes rises as the context window fills. Watch it, and compact well before the limit.
- Compaction keeps a summary and loses details that were never written down, so write the task, the decisions and the next step to files, and keep the real task list in a tracker.
- `/context` shows what is filling the context window, by category, with suggestions.
