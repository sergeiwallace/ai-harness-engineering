# Coordinating several sessions

As of 2026-11-09.

Stop 7 on the talk path, about 2 minutes.

- A coordinator session takes requests and hands them out, so the person deals with fewer places.
- Sessions message each other with `SendMessage` and `ListAgents`, with mail and inbox systems as fallbacks.
- `/list-agents` lists the sub-agents and other sessions this session can message.
