# Advanced session coordination topics

As of 2026-11-09.

- My full message order. On one machine: `SendMessage` first, then two fallbacks. Across machines: native delivery, then Agent Mail, then Buzz, then the git inbox, then a last-resort channel.
- Agent teams let agents message each other directly. They are experimental and turned on with an environment flag, and a teammate cannot start a team of its own.
