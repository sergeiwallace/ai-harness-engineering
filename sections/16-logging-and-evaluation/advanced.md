# Advanced evaluation topics

As of 2026-11-09.

- Two terms from Anthropic's eval guide: pass@k counts a task as solved if any of k attempts succeeds, and pass^k only if all k succeed. Capability evals find what the agent can do; regression evals stop it from losing ground.
