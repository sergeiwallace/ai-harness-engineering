# Skills, commands and plugins

As of 2026-11-09.

Stop 4 on the talk path, about 1.5 minutes.

- A skill is a folder of instructions that loads only when it is used. The model can start some skills; only the person can start others.
- A plugin packages skills, hooks, agents and MCP servers so they install and share as one unit.
