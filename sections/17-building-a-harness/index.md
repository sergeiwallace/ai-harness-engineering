# Building your own harness

As of 2026-11-09.

Stop 12 on the talk path, about 5 minutes.

- Start from friction, find the part of the system that let it through, and prefer a fix that a program enforces.
- Let agents do the improvement work.
- Complexity creep: a harness can grow into a patchwork of overlapping rules, hooks and scripts that is hard to understand and maintain. Balance simplicity against building more systems around the models.
- A possible first week: one context file, one skill, one hook and one approval rule.
